## 💎 Global Interactive Features
- **Universal Slide-Out Cart Drawer**: Click the shopping bag icon on *any* page to slide open the drawer with live cart items and quick checkout.
- **Quick View Modal**: Click "Quick View" on any product card across the website to view instant details without leaving the page.
- **Global Search Overlay**: Press the search icon or type to filter all formulations instantly.
- **Wishlist Toggle**: Heart any product to save it to your wishlist (persisted across sessions via `localStorage`).
- **Toast Notifications**: Luxury feedback alerts whenever products are added to your ritual.
- **Responsive Mobile Navigation**: Side-sliding menu drawer optimized for smartphones and tablets.

## 🚀 How to Run
Simply open **`index.html`** in any web browser (Google Chrome, Microsoft Edge, Firefox, Safari) by double-clicking the file or right-clicking and selecting **"Open with..."**.
